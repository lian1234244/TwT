# Source availability / 源代码获取说明

Mineradio Mikalinsa Edition is distributed under GNU GPL v3.0. For each binary
Release, the complete corresponding Mineradio application source is available
from the Git tag attached to that Release:

https://github.com/Mikalinsa/Mineradio-derivative-work/releases

GitHub automatically provides `.zip` and `.tar.gz` source archives for each tag.
The repository also contains the build scripts and dependency lockfile needed to
build the application. See `BUILDING.md`.

Third-party components remain under their own licenses. Their source locations,
versions and license texts are listed in `THIRD_PARTY_NOTICES.md`. In particular:

- OBS Studio 32.1.2 source: https://github.com/obsproject/obs-studio/tree/32.1.2
- FFmpeg source and legal information: https://ffmpeg.org/download.html and
  https://ffmpeg.org/legal.html
- KuGouMusicApi 1.5.1 source:
  https://github.com/MakcRe/KuGouMusicApi/tree/v1.5.1

If a Release asset and its source tag do not match, stop distribution and report
the issue through the repository security contact. This document is an
availability notice, not a replacement for the license terms in `LICENSE`.
